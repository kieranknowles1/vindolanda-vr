Human Meshes

Humanoid meshes are created using MakeHuman with the following process:

It's a bit long, but I can't be bothered to automate it.

  • Design a character model
  • Assign the Unity skeleton from the MakeHuman community repository
  • Export as FBX with Scale units set to meter
  • Upload to Mixamo
  • Download rigged mesh from Mixamo and import to Unity
  • Set Model -> Normals to Calculate
  • Set Animation → Animation Type to Humanoid
  • Set Animation → Avatar Definition to Create from this model
  • Extract materials and set specular values to 0.1.
  • Create prefab variant from mesh
  • Unpack variant
  • Replace Unity Compliant Skeleton with prefab version
  • Set root animation controller to DefaultHuman
  • Disable animator Apply Root Motion
  • Add ActorAnimator component
